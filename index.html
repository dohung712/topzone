☁️ Dữ Liệu Chia Sẻ (JSONBin.io)
⚠️ Chưa setup

Dùng JSONBin.io (miễn phí) làm backend. Tất cả nhân viên mở cùng 1 file HTML → dữ liệu tự đồng bộ qua cloud.

📋 Hướng dẫn setup (1 lần duy nhất, cho Quản Lý):
1. Vào jsonbin.io → Đăng ký miễn phí
2. Vào API Keys → Copy Master Key
3. Nhấn Create Bin → nhập [] → Copy Bin ID (phần sau /b/)
4. Dán 2 thông tin vào dưới → Lưu → Chia link HTML cho nhân viên
1
Nhập Master Key từ JSONBin (bắt đầu bằng $2a$...)

2
Nhập Bin ID (chuỗi ký tự sau /b/ trong URL)

🌐 Tạo Link Dùng Chung (GitHub Pages – Free)
Miễn Phí

Sau khi setup JSONBin, deploy file HTML lên GitHub Pages để có 1 link cố định chia sẻ cho toàn bộ nhân viên.

1
Vào github.com → Đăng ký tài khoản miễn phí → Tạo New Repository tên topzone
2
Upload file topzone_v6.html → đổi tên thành index.html
3
Vào Settings → Pages → Branch: main → Save
4
GitHub tạo link: https://[username].github.io/topzone/ → Copy chia cho tất cả nhân viên!
⭐ Kết quả: 1 link duy nhất → Mọi nhân viên truy cập → Dữ liệu đồng bộ qua JSONBin → Quản lý xem phân tích tổng hợp theo ngày/tuần/tháng
🖼️ ImgBB – Upload Ảnh Lấy Link
Chưa cài

Ảnh sẽ upload lên ImgBB (miễn phí) và sinh ra link công khai. Quản lý nhấn link xem ảnh bằng chứng trực tiếp.

1
Truy cập api.imgbb.com → Đăng ký miễn phí → Get API Key
2
Copy API Key → Dán vào ô dưới → Test → Lưu
